# credit-risk-classification-system
A Machine Learning-based Credit Risk Classification System that analyzes applicant and financial information to classify loan applicants into Low or High Credit Risk using a Random Forest Classifier
📌 Project Overview
This project analyzes customer financial and personal information to classify credit risk. It assists financial institutions in making informed lending decisions.
